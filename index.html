BASYS3 · PART 02 · CHAPTER 00–20 v02

제2부 · 사용자 AXI IP와 주변장치

AXI4-Lite 사용자 IP를 직접 만들어 Basys3 주변장치를 제어하고 하나의 SoC로 통합

00학습 흐름

MicroBlaze V SoC에 AXI4-Lite 사용자 IP를 직접 설계해 붙이고, LED·FND·버튼·PWM·센서·모터·통신 주변장치를 차례로 제어합니다. 각 장은 기능 RTL, AXI 레지스터, Vitis C 제어로 나뉘며 20장에서 하나의 SoC로 통합합니다.

00장 제2부 SoC 전체 구조 ↓ 01~04장 AXI LED · FND · 버튼 인터럽트 · PWM ↓ 05~09장 CdS · 초음파 · DC 모터 · XADC · UART 모드 통합 ↓ 10장 주변장치 종합제어 (10.3 IP 라이브러리 사양) ↓ 11~19장 서보 · 스테핑 · SPI RFID · I²C LCD · 1-Wire · RTC · DHT22 · PIR · BME280 ↓ 20장 종합 통합 · 안전 인터록 각 장 NN.1 C 코드 풀이 · NN.2 RTL·AXI 풀이 (01~10장), 12.1~12.4 스테핑 모터 실습

각 장은 앞 장의 Vivado·Vitis 프로젝트를 새 이름으로 복제해 이어서 만듭니다. 앞 장 프로젝트는 그대로 둡니다.

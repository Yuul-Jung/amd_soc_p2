01개요

Basys3 FPGA 3.3V 출력 4개로 ULN2003의 IN1~IN4를 제어한다. 28BYJ-48 모터는 ULN2003 드라이버의 5핀 소켓에 꽂고, 모터 전원은 별도 안정화 5V에서 공급한다.

이 단계는 실제 배선과 전기적 확인이 필요하다.

02연결 구조

03Basys3 JC 핀 후보

Digilent 공식 Basys3 Master XDC의 JC1~JC4를 사용 가능 후보로 선정했다. 다만 11장 서보 및 기존 주변장치가 이미 JC를 사용하고 있다면 다른 여유 Pmod 핀을 선정해야 한다.

04배포용 XDC 후보 코드

XDC 후보 파일 열기. 실제 프로젝트의 기존 XDC와 병합할 때에는 같은 핀을 이중 지정하지 않는다.

05전원·보호 절차

  1. 보드 및 외부 전원 모두 OFF 상태에서 신호/모터 커넥터를 연결한다.
  2. 28BYJ-48이 실제 5V 모델인지 라벨과 판매 회로를 확인한다. 12V 모델과 혼동하지 않는다.
  3. ULN2003 5V 단자와 외부 안정화 5V를 연결하고 Basys3 GND를 공통으로 연결한다. 5V는 Basys3 I/O 핀에 연결하지 않는다.
  4. ULN2003 보드의 IN1~IN4 입력이 FPGA 3.3V 논리 출력에서 안정적으로 HIGH로 인식되는지 실제 모델 회로와 데이터시트로 확인한다.
  5. 케이블 고정·노출 접점·접지 단락을 점검하고, 처음에는 기계 부하를 제거한다.
  6. 먼저 제어핀과 GND만으로 ULN2003 상태 LED를 확인한 뒤 모터 전원 인가 순서를 진행한다.

ULN2003의 입력은 일반 TTL 계열 호환 방식이지만 보드별 저항·LED·배선이 다를 수 있다. 특정 판매 모듈의 전기적 적합성을 실물 검사 없이 성공 판정하지 않는다.

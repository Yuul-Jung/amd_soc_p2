01사용자 AXI IP의 역할

A · 하드웨어
MicroBlaze V → AXI4-Lite Write(REG0) → slv_reg0[0] → led_o → p2_led_o → LED0

기존 Wizard 생성 AXI4-Lite Slave의 쓰기·읽기 로직을 재사용합니다. slv_reg0는 AXI가 쓴 데이터를 보관하는 플립플롭 레지스터입니다. led_o는 이 값의 최하위 bit0을 배선으로 전달합니다.

현재 실제 Wizard 생성 파일은 사용자가 아직 만들지 않았습니다. 여기의 예시는 포트 삽입 원리를 설명하며, 실제 파일과 slv_reg0 구조를 확인한 뒤 적용합니다. 을 함께 사용합니다.

02두 파일의 수정 위치

B · RTL 수정
파일삽입 위치·내용
p2_01_axi_led_v1_0.v상위 module 선언부의 출력 포트 목록에 output wire led_o 추가. p2_01_axi_led_v1_0_S00_AXI 인스턴스 포트에 .led_o(led_o) 추가.
p2_01_axi_led_v1_0_S00_AXI.v하위 module 출력 포트 목록에 output wire led_o 추가. slv_reg0 선언 확인 후 모듈 내부에서 assign led_o = slv_reg0[0]; 추가.

추가 코드 ① 상위 파일:

명령·출력
module p2_01_axi_led_v1_0 #(/* 생성한 파라미터 유지 */)(
    // ... 기존 포트 유지
    output wire led_o,  // (추가) 보드 LED로 나갈 출력
    // ... 기존 AXI 포트 유지
);

// 기존 S00_AXI 인스턴스의 포트 연결 목록에 추가
.led_o(led_o),

추가 코드 ② 하위 파일:

명령·출력
// S00_AXI 모듈 포트 선언부에 추가
output wire led_o,

// S00_AXI 모듈 내부에 추가 (slv_reg0 선언 확인 후)
assign led_o = slv_reg0[0];
위 예시는 삽입 위치를 보여주는 변경 조각입니다. 말줄임표를 RTL에 입력하지 않습니다. 실제 Vivado가 만든 전체 포트 이름과 충돌하지 않도록 선언부를 대조해야 합니다.

03BD → Wrapper → Top 순서

C · 연결
명령·출력
p2_01_axi_led_v1_0_S00_AXI.slv_reg0[0]
      ↓ assign led_o
p2_01_axi_led_v1_0.led_o
      ↓ Make External, rename p2_led_o
soc11_integration_wrapper.p2_led_o
      ↓ .p2_led_o(ip_led0)
basys3_soc11_top.led[0]

기존 led_tri_o[15:0]는 전체를 LED 외부 포트에 다시 연결하지 않습니다. 사용자 Top 전체 소스에서는 led[15:1]만 기존 GPIO에 연결하고 bit0은 새로운 사용자 IP에서 받습니다.

PART 02 · CHAPTER 01

04실습 파일

P2_01_basys3_top.v · Verilog
// 제2부 01장(P2-01) 사용자 Top — 보드 연결 전용
// (변경) LED0을 신규 AXI IP 단독 출력에 연결한다.
// (유지) LED1~15, SW, UART, Clock, Reset은 기존 Wrapper에 연결한다.
module basys3_soc11_top (
    input  wire        clk,     // Basys3 100 MHz: W5
    input  wire        btnC,    // 기존 시스템 Reset: U18
    input  wire [15:0] sw,      // 기존 스위치 입력
    output wire [15:0] led,     // 내장 LED[15:0]
    input  wire        RsRx,    // PC -> FPGA UART
    output wire        RsTx     // FPGA -> PC UART
);
    wire [15:0] gpio_led;       // 기존 AXI GPIO 출력, bit0은 미사용
    wire        ip_led0;        // 새 사용자 AXI IP 출력

    // (변경) 결합된 신호를 보드 출력에 연결한다.
    // LED[15:1]은 gpio_led[15:1], LED[0]은 ip_led0으로 연결.
    // 연산이나 상태 결정이 아닌 단순 배선이다.
    assign led = {gpio_led[15:1], ip_led0};

    soc11_integration_wrapper u_soc11 (
        .clk(clk),
        .btnC(btnC),
        .sw_tri_i(sw),
        .led_tri_o(gpio_led),
        .UART_0_rxd(RsRx),
        .UART_0_txd(RsTx),
        .p2_led_o(ip_led0)       // BD에서 외부화한 포트; 생성 Wrapper와 대조
    );
endmodule

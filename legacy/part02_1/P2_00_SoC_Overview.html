📘 제2부 00장 — 사용자 AXI IP 기반 SoC 전체 구조

Basys3 + MicroBlaze V SoC · 제2부 01~10장 통합 안내서

1. 과제 개요

제1부 MicroBlaze V SoC에 사용자 AXI4-Lite(에이엑스아이 포 라이트, 경량 메모리 맵 제어 버스) IP를 단계적으로 추가한다. 01~07장 사용자 IP 7종, 08장 AMD XADC, 09장 UART·IRQ 통합, 10장 종합 제어를 다룬다.

2. 전체 SoC 시스템 구조

CPU는 AXI Interconnect를 통해 각 IP의 레지스터에 접근하며, 기능별 RTL Core는 독립적으로 동작한다.

그림 2-1. 사용자 AXI IP와 AMD 제공 IP의 논리적 분류. 실제 Vivado Block Design 배선과 구분한다.

4. IP 내부 구조

MicroBlaze V CPU ↔ AXI4-Lite 레지스터 ↔ RTL Core ↔ 주변장치. 실제 Register Map은 장별 RTL 기준이다.

7. Vivado·Vitis 공통 절차

  1. 직전 장의 실제 성공 프로젝트 독립 복제
  2. 사용자 IP 생성·RTL Core 연결
  3. IP Package 후 Catalog 등록
  4. Block Design에 AXI·Clock·Reset·IRQ 연결
  5. Address Editor 및 Validate Design 확인
  6. Wrapper·Top·XDC 연결, 합성·구현·Bitstream·XSA 생성
  7. Vitis에서 실제 주소 확인 및 C 프로그램 빌드
  8. 실물 보드 동작 확인

Top Module은 보드 입출력·배선·인스턴스 연결만 담당한다.

8. CPU와 RTL의 역할

CPU는 명령 해석·설정·상태 관리, RTL은 정밀 타이밍·병렬 동작·하드웨어 보호를 담당한다.

10. 최종 핵심 정리

제2부는 사용자 AXI IP 7종과 AMD 제공 IP를 결합하고 09~10장에서 누적 통합한다. 각 장은 직전 장의 기능을 유지하면서 새 기능을 누적한다.

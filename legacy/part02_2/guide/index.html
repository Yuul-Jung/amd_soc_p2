00제2부 후반부 교육과정

Basys3 FPGA 및 MicroBlaze V 기반 주변장치·센서·액추에이터의 제어 구조를 익히고, 개별 RTL 검증부터 통합 인터록 설계까지 진행합니다.

실습은 개념 → 블록 구조 → 신호·레지스터 → 전체 코드 → 실행 → 검증 순으로 구성합니다. 11~19장의 기능을 모두 실제 보드에서 연결했다고 전제하지 않으며, 20장은 일부 기존 RTL의 제한된 통합 시뮬레이션입니다.
